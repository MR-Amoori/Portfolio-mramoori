=== آموزش‌ها ===

1. تغییر بین محیط‌های LocalHost و Production:
   - برای تغییر به محیط LocalHost، در فایل Startup.cs خط زیر را فعال کنید:
     string connetcionString = Configuration.GetConnectionString("LocalHost");
   - برای تغییر به محیط Production، خط زیر را فعال کنید:
     string connetcionString = Configuration.GetConnectionString("Production");

2. پابلیش پروژه:
   - ابتدا پروژه را Build کنید:
     dotnet build --configuration Release
   - سپس پروژه را Publish کنید:
     dotnet publish --configuration Release --output ./publish
   - فایل‌های Publish شده در پوشه ./publish قرار می‌گیرند.

3. تغییر Connection String:
   - Connection String را در فایل appsettings.json تغییر دهید.
   - سپس پروژه را مجدداً Build و Run کنید.
